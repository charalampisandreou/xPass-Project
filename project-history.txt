## 3. METHODOLOGY & MACHINE LEARNING FRAMEWORK
- Core Mathematical Framework: The model treats pass completion as a Bernoulli event framework where every individual pass is a discrete conditional action yielding a binary outcome (1 = Completed, 0 = Incomplete/Intercepted).
- The "Time-to-Execute" Temporal Innovation: Replicating Lamberts' blueprint, the model introduces a custom temporal delta feature. By calculating the chronological difference (in milliseconds) between a player's "Ball Receipt" event and their subsequent "Pass" release, the pipeline mathematically quantifies decision-making speed and pressure dynamics.
- Advanced Spatial Features (The StatsBomb Freeze Frame Layer): To prevent the model from becoming generic, the architecture leverages StatsBomb's coordinate snapshots. Features include calculating Euclidean distances to goal, relative angles, proximity pressure vectors, and counting opposing defenders intersecting a custom geometric passing lane wedge.
- Evaluation Metrics & Validation: The model's out-of-sample predictability will be rigorously evaluated using a match-based 80/20 train-test split (targeting ~160,000 training rows and ~40,000 hidden test rows). Success criteria will be mathematically measured using Brier Scores, Log Loss curves, and ROC AUC metrics.
